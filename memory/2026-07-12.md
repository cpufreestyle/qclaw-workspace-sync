### 技术总结
1. **watcha.cn SPA 架构**: Vue.js SPA，课程内容通过 API 动态加载，需要浏览器渲染（xbrowser/CfT）
2. **ProseMirror 编辑器交互**: 富文本编辑器需要 CDP Input.dispatchKeyEvent 或直接 API 提交（fill/type 无法触发 Vue 状态更新）
3. **作业 API 端点**:
   - GET /camp-api/homework/find?postId=xxx（获取作业信息）
   - POST /api/v2/discuss/floors（提交评论，参数用 post_id 非 postId）
   - POST /camp-api/homework/submit（提交作业）
4. **Token 刷新**: 访问 watcha.cn API 需先获取 JWT token，token 会过期需通过 refreshToken 刷新
5. **飞书问卷**: 使用自定义 React 组件，radio 点击后状态未同步需要通过 DOM 事件触发，contenteditable div 需要 input 事件监听
