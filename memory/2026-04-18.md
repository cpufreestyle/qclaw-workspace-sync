### 🦞 1. 龙虾 = OpenClaw
- GitHub: `openclaw/openclaw`
- "Your own personal AI assistant. Any OS. Any Platform. The lobster way. 🦞"
- TypeScript/Node.js, Skills 系统, MCP, 多渠道Gateway

### ☤ 2. 爱马仕 = Hermes Agent
- GitHub: `NousResearch/hermes-agent`
- "The self-improving AI agent built by Nous Research"
- 核心：自学习闭环（从经验创建技能→使用中改进→持久化知识→搜索历史）
- 多模型：OpenRouter(200+)、NVIDIA NIM、小米MiMo、Kimi/Moonshot、MiniMax、OpenAI等
- 多平台：Telegram、Discord、Slack、WhatsApp、Signal、CLI
- 子代理并行、内置cron、6种运行后端（本地/Docker/SSH/Daytona/Singularity/Modal）
- 支持OpenClaw迁移：`hermes claw migrate`
- Web UI: `pyrate-llama/hermes-ui`（单文件HTML+React18，毛玻璃设计）

### 🏛️ 3. 记忆宫殿 = Memory Palace
- GitHub: `AGI-is-going-to-arrive/Memory-Palace`
- "AI Agent 的长期记忆操作系统"
- Python + FastAPI + React + SQLite + MCP协议
- 核心功能：
  - 持久记忆存储（跨会话不丢失）
  - 混合检索（关键词+语义+reranker），意图感知搜索
  - 写入守卫（Write Guard预检查），快照回滚
  - 统一MCP协议集成 Codex/Claude Code/Gemini CLI/OpenCode
  - Dashboard：Memory、Review、Maintenance、Observability
- v3.7.1，Docker支持

### 🧠 4. AILinkX
- GitHub: `iniwap/AILinkX`
- "全能数字生命操作系统"
- 核心爆点：
  - 🧠 全息记忆宫殿：本地RAG架构，语义检索，问答式查询
  - 💓 情感雷达：潜台词解码，矛盾猎手（实时比对历史画像）
  - 🧬 数字分身养成：风格克隆LoRA，自动托管
  - 🤖 智能事务官：自动归档、日程预约、财务助手
- 非侵入式架构：视觉感知UI，不注入DLL，拟人化引擎
- Local-First，所有数据本地存储
- ⚠️ 目前封闭开发，未开源（Star 5k开源SDK，10k开源记忆模块，10w开源驱动层）
